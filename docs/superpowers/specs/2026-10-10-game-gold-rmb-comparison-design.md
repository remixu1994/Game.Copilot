# 游戏金币 RMB 价格对比设计

## 目标

更新枫币估价页的默认汇率，并将三种游戏金币获取方式统一换算为“1 亿游戏金币需要多少 RMB”，合并到“常见商店物品 RMB 估价”列表中。

## 默认价格体系

- 默认实时汇率：`48 RMB = 38,570 枫币`。
- 默认不扣除枫币交易手续费。
- 如果浏览器保存的价格仍是旧默认值 `15 RMB = 12,857 枫币` 且启用了手续费，则自动迁移到新默认值。
- 用户自行修改过的汇率、手续费选项和礼包配置继续保留。

## 游戏金币渠道

| 渠道 | 支付 | 获得游戏金币 |
| --- | ---: | ---: |
| 兑换所 | 3,600 枫币 | 63,528,000 |
| 水晶商店 | 140 红钻 | 50,000,000 |
| 私人商店 | 340 红钻 | 100,000,000 |

兑换所使用当前人民币—枫币汇率计算；水晶商店和私人商店使用当前 185 元礼包推导出的红水晶 RMB 单价计算。因此修改统一价格体系后，三项结果同步更新。

## 列表展示

三种渠道作为“常见商店物品 RMB 估价”中的独立行，展示：

- 渠道名称。
- 原始兑换条件。
- 该笔兑换的 RMB 成本。
- 统一归一化结果：`1 亿游戏金币 = X RMB`。

游戏金币渠道内部按“每 1 亿金币 RMB 成本”从低到高排列，最便宜的渠道置顶。原有自动战斗券等常见物品继续保留，不与金币渠道混合做价格排名。

## 计算接口

新增纯计算层：

- 输入：渠道定义、当前枫币 RMB 单价、当前红水晶 RMB 单价。
- 输出：原始兑换 RMB 成本、每 1 亿金币 RMB 成本。
- 无效或零数量数据返回安全结果，不产生 `Infinity` 或 `NaN`。

React 页面只负责渲染计算结果，渠道数据和计算公式保持在可单元测试的 TypeScript 模块中。
